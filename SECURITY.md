# Security Policy

## Sensitive Data

Do not commit:

- Claude `sessionKey` values.
- Cookies, tokens, API keys or bearer tokens.
- `.env` files.
- Local runtime JSON files such as `settings.json`, `notifications.json` or history files.
- Logs generated by the app.
- Certificates or private keys.
- Published binaries and installer artifacts.

The application stores sensitive provider credentials through Windows Credential Manager on Windows and the user's default Keychain on macOS. Normal settings and history are stored locally under `%LOCALAPPDATA%\AIUsageWidget` or `~/Library/Application Support/AIUsageWidget/` respectively.

The macOS WebKit helper receives credentials only through an anonymous stdin pipe, uses an ephemeral browser data store, and does not include secrets in process arguments or diagnostics. Signing certificates and notarization credentials must remain outside the repository.

## Claude Integration

The Claude integration is non-official and uses isolated web endpoint access. It may break if Claude changes authentication, session handling or response formats.

The application must not log session keys, cookies, authorization headers or full credential values.

## Reporting Security Issues

If this repository is public, report security issues privately to the repository owner instead of opening a public issue with sensitive details.
